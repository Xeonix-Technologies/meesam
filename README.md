# Meesam (ميسم)

Trademark management platform by Xeonix Technologies — owners, agencies and staff; Arabic and English at launch.

- `apps/web` — Next.js application and public site
- `apps/worker` — job-table runner (timers, notifications, watch pipeline)
- `apps/embeddings` — Python service for mark similarity models
- `packages/db` — Drizzle schema and SQL migrations
- `packages/i18n` — locales and messages
- `packages/ui` — design tokens and components
- `docs/` — specification documents of record (read `CLAUDE.md` first)
- `infra/` — Railway layout and variable references

Branches: `develop` → staging, `main` → production. See `CLAUDE.md` for the engineering rules.
